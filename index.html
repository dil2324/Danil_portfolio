PYTHON DEVELOPER

Мой фокус — backend на Python:
от REST API до AI-ассистентов.

Разрабатываю серверную часть веб-приложений на FastAPI. Работаю с внешними API, асинхронными запросами и базами данных. Встраиваю LLM в приложения и сохраняю контекст диалога.

В проектах уделяю внимание аутентификации, валидации данных и тестам. Использую PostgreSQL и SQLAlchemy для хранения данных, Docker Compose — для запуска окружения.
