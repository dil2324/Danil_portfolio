# Данил — Python Backend Developer

Один статический сайт-портфолио: проекты, навыки, опыт работы, резюме и контакты. Работает без сборки, API-ключей и платного сервера.

## Посмотреть локально

Откройте `index.html` в браузере или запустите из папки проекта:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Затем откройте http://localhost:8000. Копирование email использует Clipboard API; на локальном файле браузер может его ограничить, поэтому предпочтителен localhost.

## Одна публичная ссылка через GitHub Pages

1. Создайте публичный репозиторий `dil2324.github.io` в аккаунте `dil2324`.
2. Загрузите `index.html`, `styles.css`, `app.js`, `favicon.svg` и `.nojekyll` в корень ветки `main`.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Выберите **main** и **/(root)**, нажмите **Save**.
5. После успешного развёртывания GitHub покажет адрес сайта: `https://dil2324.github.io/`.

Это будущий адрес после публикации, не утверждение о том, что сайт уже опубликован. Если репозиторий уже существует, сначала проверьте его содержимое и не заменяйте существующий сайт без необходимости. Для репозитория с другим названием адрес будет `https://dil2324.github.io/название-репозитория/`; относительные пути этого сайта подходят для обоих вариантов.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Где менять содержимое

- `index.html` — имя, специализация, опыт, навыки, контакты и ссылка на резюме.
- `app.js` — массив `projects`: названия, описания, технологии, ссылки и подробности проектов. При добавлении работ обновите число проектов в навигации и фильтре «Все» в `index.html`.
- `styles.css` — оформление, адаптивная вёрстка и цвета двух тем.
- `favicon.svg` — значок во вкладке браузера.

Описания проектов взяты из публичных README на GitHub `dil2324`. Опыт Adzuna и контакты предоставлены владельцем портфолио. Имя «Данил» взято из названия папки проекта; полное имя не предоставлено. Графика на карточках — иллюстрации, а не скриншоты проектов. Для AI Assistant Bot есть ссылка на настоящую запись демо в репозитории.

Сайт не обращается к вашим API и не раскрывает ключи. Backend-приложения и боты продолжают работать на своём хостинге; портфолио объединяет их описания и ссылки. Ссылки на внешние демо взяты из README, их доступность зависит от соответствующего сервиса. Шрифты загружаются с Google Fonts; при отсутствии сети используются системные шрифты.

## Возможности

- Адаптивная вёрстка для телефона и компьютера.
- Фильтрация работ: Backend, Боты, Frontend.
- Описания проектов в диалоге с закрытием по Escape.
- Светлая и тёмная темы с сохранением выбора.
- Мобильное меню, копирование email, ссылки для звонка и письма.
- Поддержка клавиатуры и `prefers-reduced-motion`.
